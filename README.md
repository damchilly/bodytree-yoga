# BodyTree Yoga

First-version landing page for the BodyTree Yoga studio.

## Run locally

```bash
cd bodytree-yoga
pip install -r requirements.txt
python app.py
```

Then open [http://127.0.0.1:5000](http://127.0.0.1:5000).

## What's included

- Custom logo (SVG + generated mark)
- Full-bleed hero landing section
- Tabbed subsections: Home, About, Services, Contact
- Contact form (client-side confirmation for this first version)
